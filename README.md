# Routewise – In-game GPS

[English](#english) · [Deutsch](#deutsch)

World of Warcraft addon for **WoW Forever** · Author: Rottgar85

---

## English

**A GPS for Azeroth.** Pick a zone, dungeon or raid and Routewise plans the fastest route for you, using flight masters, ships, zeppelins, the Deeprun Tram and walking paths. A car-style navigation display then guides you step by step.

### Features
- **Route planner**: choose a destination from the **Zones**, **Dungeons** and **Raids** tabs, or search for it. Routewise compares walking, flying and boats and shows every step with the total travel time
- **Map waypoint as destination**: set a waypoint on the world map (Ctrl+click) and let Routewise take you there
- **Navigation display**: turn arrows (left, right, keep left, turn around …), distance to the next step, remaining time and arrival time. Drag to move, Ctrl+mouse wheel to resize
- **Flight masters, ships, zeppelins and tram**: the route only uses flight paths your character knows. Talk to a flight master once and it is used from then on. Measured flight times are remembered account-wide
- **Avoids hostile towns**: routes go around enemy camps and the capitals of the other faction (can be turned off)
- **Re-routing**: if you leave the planned path, Routewise plans a new route
- **World map and minimap**: the route menu can open next to the world map; minimap button (left-click: menu, right-click: options)
- **Settings** in *Esc → Options → AddOns → Routewise*
- **11 languages**: English, German, French, Spanish (EU/LatAm), Italian, Portuguese (BR), Russian, Korean, Chinese (Simplified/Traditional)

### Commands
| Command | What it does |
|---|---|
| `/rwise` or `/routewise` | Open or close the route menu |
| `/rwise options` | Open the settings |
| `/rwise map` | Use the world map waypoint as destination |
| `/rwise stop` | Stop the current route |
| `/rwise arrow` | Turn the navigation display on or off |
| `/rwise here` | Show your current map position |
| `/rwise debug` | Show what Routewise has loaded (zones, instances, flight masters) |

### Installation
Install it with the CurseForge app, or unpack the ZIP into `World of Warcraft\_forever_\Interface\AddOns` so you end up with the folder `Routewise`.

## Deutsch

**Ein Navi für Azeroth.** Wähle eine Zone, einen Dungeon oder einen Raid, und Routewise plant die schnellste Route über Flugmeister, Schiffe, Zeppeline, die Tiefenbahn und Fußwege. Eine Navi-Anzeige wie im Auto führt dich dann Schritt für Schritt hin.

### Funktionen
- **Routenplaner**: Ziel aus den Reitern **Zonen**, **Dungeons** und **Raids** wählen oder suchen. Routewise vergleicht Laufen, Fliegen und Schiffe und zeigt jeden Schritt mit der gesamten Reisezeit
- **Kartenwegpunkt als Ziel**: Wegpunkt auf der Weltkarte setzen (Strg+Klick), Routewise bringt dich hin
- **Navi-Anzeige**: Abbiegepfeile (links, rechts, links halten, wenden …), Entfernung zum nächsten Schritt, Restzeit und Ankunftszeit. Ziehen zum Verschieben, Strg+Mausrad für die Größe
- **Flugmeister, Schiffe, Zeppeline und Tiefenbahn**: Die Route nutzt nur Flugrouten, die dein Charakter kennt. Einmal mit einem Flugmeister sprechen, danach wird er genutzt. Gemessene Flugzeiten werden accountweit gespeichert
- **Umgeht feindliche Orte**: Routen führen um feindliche Lager und die Hauptstädte der anderen Fraktion herum (abschaltbar)
- **Neuberechnung**: Wenn du vom Weg abweichst, plant Routewise neu
- **Weltkarte und Minikarte**: Das Routenmenü kann neben der Weltkarte aufgehen; Minikarten-Knopf (Linksklick: Menü, Rechtsklick: Optionen)
- **Einstellungen** unter *Esc → Optionen → AddOns → Routewise*
- **11 Sprachen**: Englisch, Deutsch, Französisch, Spanisch (EU/Lateinamerika), Italienisch, Portugiesisch (BR), Russisch, Koreanisch, Chinesisch (vereinfacht/traditionell)

### Befehle
| Befehl | Was er tut |
|---|---|
| `/rwise` oder `/routewise` | Routenmenü öffnen oder schließen |
| `/rwise options` | Einstellungen öffnen |
| `/rwise map` | Wegpunkt der Weltkarte als Ziel nutzen |
| `/rwise stop` | Aktuelle Route beenden |
| `/rwise arrow` | Navi-Anzeige an- oder ausschalten |
| `/rwise here` | Deine aktuelle Kartenposition anzeigen |
| `/rwise debug` | Anzeigen, was Routewise geladen hat (Zonen, Instanzen, Flugmeister) |

### Installation
Mit der CurseForge-App installieren oder die ZIP nach `World of Warcraft\_forever_\Interface\AddOns` entpacken, sodass dort der Ordner `Routewise` liegt.
